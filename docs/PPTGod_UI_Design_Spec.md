# PPTGod 界面设计规范 · 冰川白工作台

**版本 1.0 · 2026-11-25 · v7 界面改版提案**

首页要让第一次打开 PPTGod 的人能上传资料，并看清这些内容做成幻灯片是什么样子。熟悉产品的人可以直接在画廊复制提示词。资料推荐、并排对比和编辑工坊沿用同一套操作习惯。

![PPTGod 首页对照图。左侧是 v7 首页，右侧用同一科研题目展示上传入口、16:9 主预览和三张风格卡。](https://raw.githubusercontent.com/curtainchris233-hub/PPTGod/main/docs/showcase/home-ui-design-review.webp)

## 1. 首页与画廊

桌面首屏左右分栏。左侧放资料入口，右侧放一张可切换页型的真实幻灯片。画廊紧接在下方。以 1440 × 900 为设计基准，打开页面即可看见上传入口、完整主预览和第一排模板缩略图。

| 区域 | 展示内容 | 点击或输入后的结果 |
| --- | --- | --- |
| 顶部导航 | PPTGod、风格画廊、生成工坊、我的空间。已加入对比的模板用数量提示 | 从画廊可回到已有对比。发布风格从「我的空间」或更多菜单进入 |
| 左侧资料入口 | 标题「把你的资料做成可编辑 PPT」。实心蓝按钮「上传资料」，旁边放文字按钮「粘贴大纲」。下方一行显示支持格式和 10 MB 上限 | 点击上传直接选文件，也支持拖入。点击粘贴直接聚焦文本框。两者解析后进入同一个推荐视图 |
| 右侧实时预览 | 16:9 画布、带标签的「预览主题」输入框、共用的「封面 / 数据页」切换器 | 输入题目同步更新主预览与画廊卡片。切换页型时保留题目。清空后回到明确标注的示例内容 |
| 画廊筛选 | 常显领域、搜索和「筛选」。领域沿用商业、教学、科研、职场、生活五组。将场景、色系、风格、适配工具及排序收入面板 | 有筛选条件时显示数量，并提供清除入口。零结果保留搜索词，提供「清除筛选」。选词顾问从「帮我选风格」进入 |
| 模板卡 | 16:9 预览、风格名、一个场景标签，以及「用此风格」「复制提示词」。配色由模板决定 | 点预览进入风格工作室。用此风格进入工坊并携带题目与模板。复制在卡内反馈「已复制」。对比、收藏等操作放入可用键盘和触屏打开的菜单 |

首屏每个任务区只用一个实心主按钮。画廊卡的「用此风格」用文字或描边样式，以免一排蓝色按钮盖过真正需要比较的作品。

## 2. 资料推荐与并排对比

1. **先确认读到的内容。** 解析成功后显示文件名、识别场景、可编辑标题和建议页数。提取到的章节和指标可以展开核对。资料格式沿用 PDF、DOCX、PPTX、Markdown 和 TXT。
2. **给推荐理由。** 最多展示三套匹配风格。卡片用同一页内容，配一句具体理由，例如「图表旁留有结论区，便于评审同时看数据和判断」。选中卡同时显示描边、勾选标记和「已选中」。
3. **先选模板，再执行一次生成。** 推荐区共用主按钮「用所选风格生成 PPT」。次操作提供「并排对比」和「复制提示词」。复制时显示当前目标工具，切换工具继续使用同一份资料。
4. **给对比页同一份样稿。** 优先使用资料中已确认的内容。缺少内容时，各列共用一份标注为「示例」的样稿。封面对齐标题与副标题，数据页共用指标、数值、单位、顺序和刻度范围。保留各模板自己的字体、配色和图例位置。
5. **保持看图的位置。** 桌面将 2–3 个画布顶边对齐，颜色值、字体名等规格收在预览下面。手机在同一块画布上切换候选风格，当前页型与主题持续可见。其余页型从「更多页型」进入。

**可复用的评审样稿。** 封面使用「钙钛矿薄膜结晶机制」，副标题使用「原位表征与工艺窗口」。数据页使用「项目排期（示例）」以及样品准备 2 天、测试 3 天、分析 1 天。切换科研证据流、基金答辩和黑板教学三种模板，检查题目换行、图例和单位。三个天数仅用于界面排版测试。

## 3. 编辑工坊

| 用户所处阶段 | 首要内容与操作 | 其他控件 |
| --- | --- | --- |
| 新建 | 露出资料与大纲入口。预置内容标记为「示例文稿」 | 保留「先看大纲」和直接生成路径。生成参数按需展开 |
| 编辑 | 生成成功后收起素材面板，直接显示当前页。桌面从左到右是页树、画布和当前页属性 | 撤销、重做、演播靠近画布。页码和所选页在打开、关闭属性面板时保持一致。演讲备注在画布下方展开 |
| 导出 | 顶栏突出「导出 PPTX」。操作过程中显示「正在导出」，完成或失败后给出结果 | HTML / PDF、Marp 和提示词收进同一导出菜单。保存状态与分享权限独立显示，让用户看清文稿是否已保存、谁可访问 |

预览和编辑均复用项目的 `SlideCanvas`。缩放时按 16:9 等比显示，使用模板的 `VisualSpec` 绘制画面。蓝色选中框、站点阴影和操作按钮放在画布外。原生 PPTX、离线 HTML 和演播画面只呈现文稿内容。

## 4. 颜色、材质与排版

| 角色 | 建议值 | 使用位置 |
| --- | --- | --- |
| 页面底色 | `#F4F8FB` | 首页、画廊和编辑器外框 |
| 实体表面 | `#FFFFFF` | 属性栏、表单、预览的承托面。幻灯片本身读取模板底色 |
| 主文字 / 辅助文字 | `#192938` / `#4F626F` | 标题、输入值 / 说明、单位、元信息 |
| 主操作 / 悬停 | `#2563EB` / `#1D4ED8` | 上传、当前阶段的提交操作、选中标记和键盘焦点 |
| 分隔线 / 交互边界 | `#CFDCE3` / `#71828D` | 装饰性分隔 / 需要边界才能辨识的控件 |
| 成功 / 错误 | `#17735A` / `#B23A32` | 搭配图标与「已复制」「解析失败」等文字 |

- **玻璃与轻拟态。** 顶部导航、浮动对比栏和弹层可以使用白色 84% 不透明度、12px 背景模糊。模糊不可用时用白色实底。常驻卡片用细边线，菜单浮起时可用 `0 8px 24px rgba(25, 41, 56, .10)`。输入框仅用轻微内阴影。AI 节点与细线限于首屏边缘，让文字、数据图和缩略图留在清晰的底面上。
- **字体。** 首页标题沿用 `var(--font-serif), var(--font-cjk-serif), serif`，桌面 40–48px、手机 28–34px，行高约 1.2。正文和控件沿用项目无衬线中西文字体，正文 15–16px、行高 1.5–1.6。页型、筛选和可交互标签用 13–14px。长中文标题允许换行。
- **间距与圆角。** 采用 4、8、12、16、24、32、48px 间距。卡片内边距 16px，相邻模块间距 24–32px。按钮与输入框圆角 8px，模板卡 12px，浮层 16px。16:9 画布边缘完整可见。
- **动效与对比度。** 悬停、选择、展开过渡建议 120–180ms。用户选择减少动态效果时使用即时切换。普通文字对实际合成底色以 4.5∶1 为下限，传达控件或状态所必需的非文字线索以 3∶1 为下限。半透明导航应在浅色与深色模板滚过下方时分别检查。[文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 5. 屏幕宽度与操作状态

以下宽度指浏览器可用视口，单位为 CSS 像素。

| 宽度 | 首页与画廊 | 工坊与对比 |
| --- | --- | --- |
| ≥1200px | 内容最大宽度 1360px。首屏双栏，画廊三列 | 工坊保留三栏。页树约 192–216px、属性栏约 272–304px，中间留给画布。对比页可同时显示三套风格 |
| 768–1199px | 画廊两列。首屏容得下两块内容时并排，低于 960px 时将预览移至资料入口下方 | 优先折叠属性栏。页树可收成缩略条，保持画布可见。对比先显示两列，可切换第三套 |
| ≤767px | 从上到下依次放上传与粘贴、主预览、筛选、单列画廊。主要触控目标至少 44 × 44px | 页树和属性从抽屉打开。候选风格在同位置切换。关闭浮层后回到触发控件 |

| 状态 | 应显示的反馈 | 用户接下来可以做什么 |
| --- | --- | --- |
| 空白 / 拖入文件 | 显示支持格式、大小上限和「粘贴大纲」。拖入时用描边和文字标明落点 | 选文件、放下文件或输入文本 |
| 解析中 / 生成中 | 显示动作和文件名或主题。限制重复提交，提供可被辅助技术读取的状态消息 | 等待结果，继续查看当前可用的预览 |
| 超限 / 解析失败 / 扫描件缺少可用文字 | 在资料入口旁写明原因，保留已输入内容。扫描件提示粘贴可用文字 | 更换文件、粘贴文本，或在网络恢复后重试 |
| 已选择 / 复制完成 | 勾选、描边和文字共同标记当前项。复制按钮短暂显示「已复制」 | 继续比较、进入工坊或再次复制 |
| 键盘操作 | 可见焦点环，建议 2px 描边、2px 外偏移。菜单、页型和按钮有可读名称 | Tab 能到达主操作及更多菜单。弹层打开后焦点进入面板，Esc 关闭后焦点返回 |

## 6. 开发顺序与验收

| 顺序 | 建议从这些现有文件开始 | 可交付结果 |
| --- | --- | --- |
| 第一轮 | `src/components/GalleryClient.tsx`、`src/components/PromptCard.tsx`、`src/components/Navbar.tsx`、`src/app/globals.css` | 首页主入口、实时主预览、精简筛选、模板卡操作和共用视觉样式 |
| 第二轮 | `src/components/DocIntakeWorkbench.tsx`、`src/components/CompareClient.tsx`、`src/components/SlideCanvas.tsx`、`src/styles/doc-intake.css` | 同题同数据对比、推荐理由、单一生成按钮，以及导入状态 |
| 第三轮 | `src/components/GenerateClient.tsx`、`src/components/generate/SlideTreeSidebar.tsx`、`src/components/generate/SlidePropertyInspector.tsx`、`src/styles/generate.css` | 工坊画布优先布局、属性抽屉和导出菜单 |

- [ ] **1440 × 900。** 首屏同时呈现上传资料、完整主预览和首排模板缩略图。复制提示词从卡片一步可达。
- [ ] **1024 × 768。** 在工坊选择幻灯片、编辑属性再收起面板，回到同一页画布。导出操作可达。
- [ ] **390 × 844。** 能上传或粘贴，切换封面与数据页，在同一位置比较两套模板。页面无意外横向滚动。
- [ ] **同题对比。** 用评审样稿切换三套风格。标题、数值、单位和排序一致，可看出排版差异。空主题回到同一份示例。
- [ ] **错误与恢复。** 分别尝试大于 10 MB 的文档和缺少可提取文字的 PDF。原因与下一步在入口旁可见，已输入的大纲仍可继续使用。
- [ ] **键盘与导出。** 只用键盘完成挑选、对比和关闭弹层。导出一张封面和一张数据页，核对模板颜色、内容和 16:9 比例。
